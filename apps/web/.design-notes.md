# UI beautification — design notes

## Subject
马帮导出工作台 (Mabang export workbench). Guangzhou **apparel** company. Operators turn
NAS product folders (mens tees → colors → size runs XS–XXXL, size charts, watermarks)
into marketplace listing drafts, all day. The screens named by the user
(商品维护 / 点击"维护" / 模板维护 / 副本检查) are the data-entry surfaces of a
garment **tech pack**.

## Point of view: the cutting-room spec sheet
These maintenance/editor screens should read like a tailor's tech-pack / spec sheet
laid on the cutting-room bench — not a generic SaaS form. The codebase already reserved
`--kraft` (#8b7355, hang-tag / craft-paper brown) "brand-only". I promote it from
near-unused to the STRUCTURAL identity accent for these document-style screens.

## Tokens (additive — indigo stays the action color, do NOT break muscle memory)
- --kraft #8b7355 → section field-codes, stitch rules, spec labels
- --kraft-deep #6f5a41, --kraft-soft #f4efe6 (craft-paper wash), --kraft-line #e6dcc9
- Status glyph system untouched. Indigo primary buttons untouched.

## Type
Keep Inter + JetBrains Mono. The mono "eyebrow" becomes the spec-sheet FIELD CODE.
Section heads get a kraft chalk-tick before the code.

## Signature (spend boldness here, keep everything else quiet)
**The stitch rule + field-code header.** Under every section head runs a dashed kraft
hairline — the seam/stitch of a garment — turning each section into a spec-sheet field
row. Modal headers get a warm kraft-paper band with a kraft top rule (the tech-pack
cover). One motif, applied consistently across the three editors; no scattered effects.

## Restraint
Chanel test: one signature (kraft spec framing). No new load animations. Respect
reduced-motion (already handled). Don't recolor primary actions. Cards get polish, not
costume.
