# v1.0.103

- 修复商品描述里的尺码表图偶发跑到正文最前面（警告 `description_size_chart_position_not_at_tail`）。走「上传图片」把本地尺码表传进描述时，wangEditor 按它自己记住的光标落图，绝大多数会插到正文开头；位置校验发现后按 Ctrl+Z 撤回，但原来的撤销只按 3 次、间隔 200ms，经常全打在还没压栈的空历史栈上，图只能留在原处。
- 撤销改为先静置 350ms，再按「图数 + 3」次（最多 20 次）、每次 300ms 撤销并逐次复核。
- 撤销仍不生效时增加 DOM 兜底：只把这次刚插进去的图从编辑器摘掉（按整串地址或文件名匹配，CDN 换域名也认得出，不动正文和旧图），再按地址把尺码表插回正文末尾。
- 步骤结果里区分恢复方式：`size_chart:upload-reinsert`（撤销生效）与 `size_chart:upload-dom-removed`（走 DOM 兜底）；`rollbacks` 每轮带上 `method`，排查时能看出走的是哪条路。
- 新增回归脚本 `scripts/verify_description_media_rollback.cjs`（整串地址命中、CDN 换域名按文件名命中、不匹配时一张都不动）。
