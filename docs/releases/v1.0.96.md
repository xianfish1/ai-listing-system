# v1.0.96

本版把「店铺模板」改成**按站点隔离**：一家马帮店铺可以同时挂多个站点（菲律宾 / 马来 / 印尼 …），每个站点各自一套类目方案、模板与副本，互不覆盖，也不再因为「店铺已记录为站点 PH」而拦下 ID 的导入。

## 修了什么

- **店铺登记按站点拆开**：`mabang_store_options` 唯一键从 `(账号, 平台, 店铺)` 改为 `(账号, 平台, 店铺, 站点)`。同一家店可以同时有 PH、ID 等多条登记，互不覆盖。
- **店铺模板身份加站点**：`(刊登模式, 店铺, 站点, 类目)`。以前同一家店两个站点若选中同名类目（各站点 category_id 相同）会互相覆盖属性，现在各存各的；存量没有站点的模板按「唯一一条无站点记录」平滑升级。
- **导入不再硬拦站点不一致**：原来 `店铺「ID-Pod 2」已记录为站点 PH，与本次导入选择的 ID 不一致` 会整单失败；现在只是导入结果里多一条提示（新增独立站点记录，既有站点数据不受影响）。
- **顺手修正纯跨境站点口径**：CNSC 全球商品页的模板站点固定为 `GLOBAL`，不再被导入弹窗选的站点覆盖。

## 店铺模板编辑器

- 新增「记录站点」下拉（9 个站点全列，已登记标「（已记录）」）。
- **切换站点会切换对应的分类属性**：立即按新站点的类目方案重绑，属性行换成该国家采集到的那套；该站点还没有方案时清空并提示「先在该站点采集一次当前页」，绝不跨国家混用。
- 保存模板时自动把所选站点补成该店铺的站点登记（要求模板已有类目 + 类目方案）。
- 新增「删除该站点记录」：只删站点登记，该站点的模板 / 类目方案 / 刊登副本都保留。
- 店铺下拉按店铺去重（多站点显示 `站点 PH/ID`）；另存为模板多了「目标站点」；模板卡片显示「记录站点 · ID 印尼」。
- 导入弹窗的站点预填：该店只记了一个站点才回填，多站点留空强制手选。

## 防串味的口径

- 类目方案必须与模板站点同国家（profile.country 对得上）。
- 类目树必须是该站点采集的那一棵。
- 这两条不满足就拒绝保存，不会静默回退。
