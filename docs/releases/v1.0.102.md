# v1.0.102

- 修复自动上架偶发失败：任务在「保存前校验」被拦成 `pre_save_validation_failed`，详情里只有一条「商品标题: 请输入商品标题」，重试后又能正常保存。根因是页面重渲染把标题输入框刷空、随后补回，但 Element UI 的旧行内错误和顶部「N 必填项未填」没有跟着当前值重算，校验闸把它当成了真缺。
- 自动上架新增「保存前复核标题与 Parent SKU」：保存前再确认一次这两格，被页面刷空就地补回并 blur 确认，最多复核两轮。
- 标题填写后立即 blur 确认，把值真正写进页面模型，避免只改 DOM、页面模型仍为空。
- 保存前校验改成按「这一格当前的值」判断：已经有值、只是挂着旧「请输入…」错误的行内错误不再拦截；价格这类非必填类错误照旧拦下，真空的必填项照旧失败。
- 执行详情新增步骤文案「保存前复核标题与 Parent SKU」。
- 新增回归脚本 `scripts/verify_pre_save_validation_stale_errors.cjs`（5 条用例：有值+旧错误放行、真空白必填照拦、nav 旧计数放行、价格类错误照拦、标题被刷空能补回）。
