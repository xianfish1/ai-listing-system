# v1.0.84

本版三件事：**平台类目树按国家共用**、**活动目录按店铺（含未采集提示）**、**默认 SKU（白T恤）新建模板自动预填**。

## 平台类目树：按国家共用（不按店铺）

- 同一国家（同一平台）的不同店铺共用同一套平台类目：新店铺还没采集过类目树时，选类目自动回落到同国家其它店铺的树（按 `category_id` 去重，类目 id 是平台级的，各店铺一致）。
- 店铺已经有自己的树时仍用自己的那份（严格隔离，不混入别家的节点）。
- **跨国家绝不混用**：菲律宾不会看到印尼的类目树；跨境（GLOBAL）与本土也各自独立。
- 保存模板的内容强校验保持原样：只认本店采集到的树，本店没采过时放行（不会拿别家可能采不全的树去判某个类目"不存在"）。
- 空状态文案改为「这个国家还没有采集平台类目树……同一个国家的所有店铺共用这份类目树」。

## 促销活动：按店铺（与类目按国家共用相反）

- 同一个店铺的所有模板共用一份活动目录（采集一次即可反复选）。
- **不同店铺各自独立**：换到别的店铺后活动选择会被清空，只显示该店铺自己的活动；要重新采集。
- 该店铺一条可用活动都没有时，下拉旁明确提示「该店铺还没采集活动目录：点「重新采集活动」（浏览器要停在马帮这个店铺的商品编辑页）」。
- 回归测试锁定：同国家两家店铺各一份目录、互不共享，重采一家不影响另一家。

## 默认 SKU（白T恤）：新建模板自动预填

- 颜色名称 `PureWhite`、SKU `AL9999-PureWhite-{size}`（保存时按尺码展开成 `AL9999-PureWhite-150cm` 这类）。
- 售价 = 「交易信息」的原价；折扣价 = 六折售价，随原价/售价自动跟随。
- 手动改过默认 SKU 的价格后固定下来（不再跟随）；**清空即恢复跟随**。
- 「启用默认 SKU」复选框不自动勾选，值先填好，需要时点一下即可。
- 打开已有模板不受影响：模板里已存的默认 SKU 价格视为「操作员定过」，不会被模板价覆盖。
