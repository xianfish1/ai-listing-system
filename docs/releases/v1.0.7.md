## v1.0.7 · 2026-11-05

- **类型**：正式版
- **安装包**：`dist/ai-listing-system-1.0.7.zip`（校验值见 Release 中同名 `.sha256` 资产）

### 新增

- **商品卡人群标记与人群筛选**：商品维护的卡片在「主 SKU」那一行最右侧显示人群徽标（男童 / 女童 / 男装 / 女装），分类行新增「男童 / 女童」两枚 chip。人群只看标题关键词判断（`Boys` / `Girls` / `Men` / `Women` 及 `Mens`、`Women's` 等写法），标题里两个关键词都出现时取**最先出现**的那个（`Boys Girls` → 男童，`Men's and Women's` → 男装），单词内部的子串不算（`woman` 里的 `man`、`boyfriend` 里的 `boy`）。
- **阶段 / 人群 / 类目三轴独立筛选**：三个轴各自生效、可以叠着筛（选「男童」不会把「首次导入 / 未复制」甩掉），每个 chip 的计数按「其它两轴已生效」计算，点下去数量和筛出来的商品对得上；空列表提示会把当前生效的条件全部报出来。
- **描述插图诊断字段**：执行器结果里新增 `platform` / `is_mac` / `undo_shortcut` / `end_shortcut` / `rollbacks`，Mac 现场出问题不用再猜是撤销键没生效还是撤过头。

### 修复

- **macOS 上描述末尾插图修不好**：撤销与「跳到文末」的快捷键改按**受控浏览器**的平台切换（macOS 用 `Cmd+Z` / `Cmd+↓`），不再固定 `Control+z` / `Control+End`；CDP 连到别的机器时以浏览器为准，读不到才回退执行器所在系统。
- **新插图认错**：「上传图片」落点不受控制，插到正文前面时原来的「取末位那张」会把旧图当成新图，后续位置校验全对着错的图做。改为按插图前后的地址集合做差认新图。
- **撤销可能撤过头**：撤销不再只看图片张数，而是核对插图前快照（原有的图都还在、正文没有变短）才算恢复；恢复不了就报 `description_media_position_unrepaired` 并停下，不再一轮轮重插把描述越切越乱。
- **复用页面假装完成**：重跑或从中断阶段继续时，描述里已有的图片如果不在末尾，现在明确报 `description_media_existing_position_not_at_tail`，不再 `already:true` 掩盖一段被切坏的描述。
- **变种图「1 必填项未填」**：马帮「变种信息 → 自定义缩略图」按颜色逐个必填，颜色轴上没有专用颜色图的颜色（单色商品的占位色 `default`）现在沿用主图，不再留空导致 `pre_save_validation_failed`。
- **超大原图的变种图不显示**：4752×5120、16 MB 级原图传到「自定义缩略图」后预览一直为空，等到超时报 `variant_thumbnail_not_verified`；现在上传副本会自动缩到 2048px（原图与商品素材不动），Pillow 缺失时退回原样上传。
- **必填项误判**：`.attr-name-input`（变种属性的隐形命名框，正常页面也是空的）不再算硬缺失；保存前诊断补充控件明细（`missing_required_details` / `variant_blocks` / 只读控件数与类名），便于定位页面自动派生的「变种属性:」。

### 变更与不兼容

- 商品维护里**换分类或换时间窗会清空勾选**（以前切走之后「已选 N 个」还挂着看不见的商品，批量删除 / 重新识别会误伤）；「复制到模板」成功后同样清空勾选。
- 无数据结构变化，无接口不兼容。

### 升级提示

- 在线更新会先把旧文件备份到 `storage/updates/backups/`，不会改动 `data/`、`storage/` 和 `.env`；失败自动回滚。
- 新增依赖：无（`requirements.txt` 未变）。
- 更新后自动重启 API；如使用自定义端口，请确认 `.env` 里的 `API_PORT`。
- 配置或数据结构是否有变化：无。

### 已知问题

- 人群标记与筛选只读标题关键词，不读维护弹窗里的「适用人群」，也不是 AI 判断结果；标题改过之后要刷新列表才会更新显示。
- 描述插图如果被运营手工改乱（图在正文中间、正文被切断），执行器只报错停下、不会自动重排，需要人工调整后重跑。
