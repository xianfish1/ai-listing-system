# v1.0.91

本版在 v1.0.90 的标题裁剪修复之上，把「标题超长」提前到编辑阶段提醒：店铺刊登副本的标题编辑框会按站点显示预估上限，超限标红并支持一键按词边界裁剪；副本列表也会标红，方便在批量上架前发现。

## 新增

- **标题长度提醒（店铺刊登副本编辑器）**：标题下方实时显示「已用 N / 站点预估上限 M 字符」，超限标红并显示超出字符数；提供「按词边界裁剪」按钮，不拦截保存。
- **副本列表标红**：标题超过站点预估上限时，列表标题整格标红，并在前面显示红色「超 N」徽标。
- **站点上限表**：`services/api/site_rules.py` 新增 `TITLE_MAX_CHARS_BY_COUNTRY`。PH 按本机马帮页面实测 `maxLength=100`；MY / TH / ID / SG 等其余站点先按 120 预估；跨境多站点副本取所有目标站点里最严的上限。
- 副本列表与详情接口返回 `title_max_chars`，前端按副本的实际站点计算；旧缓存数据没有该字段时前端用同口径兜底。

## 修复（继承 v1.0.90）

- 商品标题超过马帮输入框 `maxLength` 时，执行器先按控件限长按词边界裁剪，再轮询回读 2.5 秒，避免页面截断导致 `field_value_not_verified` 整单 blocked。
- 不匹配时把 `expected / actual / max_length` 写入 `tmp_upload/auto-fill-debug.log`，便于现场定位。

## 验证

- 新增测试 `tests/test_title_length_limits.py`：PH=100、其余=120、多站点取最严。
- 扩展 `tests/test_store_listing_copy_list_ui.py`：列表标红、编辑器计数、裁剪按钮与样式。
- 用 Playwright 实际打开页面验证：AL1622 / PH 标题 103 字符 → 提示超出 3 字符 → 一键裁剪到 96 字符 → 提示恢复正常；列表显示「超 3」徽标；无前端报错。
- 相关 Python 测试 10 项通过；执行器 JS 测试 162 项通过。

## 升级提示

- 无新增依赖；不改数据结构、不改 `data/`、`storage/` 和 `.env`。
- 上限数字是**预估**，界面已标注「最终以马帮页面为准」；执行器仍按马帮页面实际 `maxLength` 兜底裁剪。
- 标题超过上限时保存不会失败，但草稿里的标题会按平台实际上限截短；完整标题仍保留在店铺刊登副本里。
