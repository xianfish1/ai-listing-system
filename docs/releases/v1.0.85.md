# v1.0.85

本版四件事：**颜色识别更准（杏色/白色/棕色）**、**AI 标题关闭时不再跑人群归类**、**Excel 导入主图顺序**、**本土「型号」属性回填**。

## 颜色识别：杏色 / 白色 / 棕色

- 颜色那一趟改用**专用提示词**（只配色，不再复用写标题/详情的长提示词）：只看布面，忽略印花、背景、道具、模特皮肤和阴影折痕；给出边界锚点——浅且带暖调 = Apricot，中性或偏冷 = White，明显更深 = Brown，并要求**同一批图片互相比较**后再命名。
- 颜色图缩图档位 **512px/70 → 768px/80**：浅杏色和白色只差一点暖调，旧档位最容易把它抹平。
- **暖中性色不再强行归板**：Cream / Ivory / Pearl / Eggshell / Tan / Camel 保留模型原话。以前是 `Cream→White`、`Tan→Brown`，正好就是现场「杏色被填成白色 / 棕色」的两种错法；认不出宁可让操作员看见再改。
- 套装/假发这类「按内容命名」的例外（Costume / Wig / Costume + Wig）保留，不影响 BF20 一类商品。
- 存量商品不会自动修正：对认错的商品点「重新识别颜色图」重跑即可。

## AI 标题关闭时跳过人群（类目）归类

- 人群归类只服务于标题规则匹配：AI 标题没开时整步跳过，**一次 AI 请求都不发**（后端加硬开关）。
- 导入进度轮播文案按设置筛：标题没开就不再显示「正在判断款式适合的人群」，只显示实际会跑的阶段。

## Excel 商品导入

- 商品图改为**按表格列顺序**（图片1（主图）→ 图片9）逐列取第一条非空地址：有的导出把图片分散在不同子 SKU 行上，旧逻辑「拿第一行有图的记录就收工」会只剩 1~3 张、顺序也丢。
- 同一个 SKU **重新导入**时整组替换该 SKU 旧的 Excel 素材记录，避免素材库里出现两套同名图片。

## 本土「型号」属性

- 副本冻结的类目快照（`category_profile_snapshot`）随任务下发给执行器：模板把属性值存成**选项 id** 时，能按快照翻回人能读的标签。
- 执行器兜底：现场重算仍判 unresolved（查不到文字）时，用 Python 侧解析出的标签填入，绝不把 `1795012147982` 这类内部 id 写进刊登；**跨境（CNSC / 3PF）路径保持原样**。
- 新增取证日志（`attribute_unresolved_option_id` / `attribute_model_plan`），型号这类字段到底走没走「添加自选值」一眼能查。
