# v1.0.93

本版修掉上架任务在「待发布商品 → 新增刊登」反复卡死的问题（`workspace_frame_not_unique`），并把刊登副本的标题长度提醒收紧到真正实测过上限的 PH。

## 修复

- **`workspace_frame_not_unique` 自动恢复**：马帮工作区残留多个「待发布商品 / 新增刊登」frame 时，原来 3 次重试全部在「打开工作区」这一步 3~4 秒秒挂，任务 blocked、Worker 暂停，只能人工重启 Worker 再点「再次尝试」。现在执行器在重试前自动做一次「重启工作区」：关掉浏览器里所有马帮页面 → 新开一页回到刊登地址 → 再走「待发布商品 → 新增刊登」。等价于手动重启 Worker，但全自动，不用人等。
- 打开工作区失败时，失败阶段如实记为 `open_workspace`（原来面板只显示 `unknown`），执行步骤里会多一条 `reset_listing_workspace`（关了几页、是否重开）。
- 整页重开只对工作区类错误（`workspace_frame_not_unique` / `mabang_detail_iframe_not_found`）触发；其它可重试错误仍只关详情页，不会白丢已填好的表单。

## 调整

- **刊登副本标题长度提醒只在目标站点含 PH 时出现**：PH 是页面实测过的 `maxLength=100`，其他站点 120 只是预估，报出来是噪音。非 PH 副本不再列表标红、不再显示计数提示，也不再提供一键裁剪；最终仍以马帮页面实际 `maxLength` 为准。列表徽标与编辑器提示同一口径。
- `index.html` 的 `app.js` 版本参数改为 `title-limit-ph-only-v1`，部署后刷新页面（F5）加载新前端。

## 验证

- 新增执行器单测 4 项（整页重开顺序、只关马帮页、重试接线、非工作区错误不重置）；`node --test tests/mabang_playwright_executor.test.cjs` **166 项全过**。
- `pytest tests/test_base_product_title_ui.py tests/test_title_length_limits.py tests/test_store_listing_copy_list_ui.py` **12 项通过**（UI 契约已同步 PH-only 口径）。

## 升级提示

- 无新增依赖；不改数据结构、不改 `data/`、`storage/` 和 `.env`。
- 执行器是每个任务新起的 node 子进程，**不需要重启 Worker**；前端改动刷新页面即可。
