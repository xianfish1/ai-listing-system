# v1.0.81

本版修复本土店铺「商品描述配图」按站点限制的问题：**马来站描述最多 3 张图、印尼站描述不允许放图**。

## 新增：描述配图按站点（国家）限制

- 规则只有一份：`services/api/description_media_policy.py`（`MY: 3`、`ID: 0`，其它站点不限）。
- 任务构建时按店铺国家下发 `description_media = {country, max_images}`，执行器只执行，不再自己维护国家表。
- **MY（马来）**：描述里一共最多 **3 张**，尺码表算其中 1 张 → 尺码表 + 2 张产品图；尺码图取不到时 = 3 张产品图。上架步骤文案同步显示「该站点描述最多 3 张图」。
- **ID（印尼）**：描述插图整步跳过（连编辑器都不碰，不再往描述里塞图）；尺码表仍走「尺码图表」字段上传，只是不进描述。
- 其它站点（PH/TW/SG/TH/MX/VN/BR 等）保持原行为：尺码表 + 全部产品图。
- 旧任务快照没有这个字段 → 按「不限」处理，不改动已完成任务的行为；排队中的任务在 Worker 用新代码重建任务计划后自动按新规则执行。

## 修复/提示：已有描述图超过站点上限

- 老草稿或复用页面里描述已经插了超过上限的图：不自动删图（删图不安全），改为给一条中文警告「描述里已有的图片超过该站点上限（马来站最多 3 张），请手动删掉多余的图」，草稿照常保存。

## 其它

- 店铺模板尺码图提示文案补一句「站点不允许描述插图时不插」；文档 `docs/MABANG_SHOPEE_BROWSER_USE_WORKFLOW.md` 同步站点上限说明。
- 测试：node 全量 271 项、pytest `test_browser_use_runner` / `test_automation_status_ui` / 新增 `test_description_media_policy` 全绿。
