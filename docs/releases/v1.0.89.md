# v1.0.89

本版把**店铺模板的多站点处理**统一收口：本土站点支持 PH / TH / MY / ID / SG（以及 TW / VN / MX / BR），跨境 3PF 继续走 GLOBAL 方案；同时修掉「模板属性值没有写进马帮」和「站点被重新导入静默改写」两个现场问题。

## 1. 站点规则集中管理（多国家）

- 新增 `services/api/site_rules.py`：`PH→PHP、MY→MYR、TH→THB、ID→IDR、SG→SGD、TW→TWD、VN→VND、MX→MXN、BR→BRL`。
- 模板、副本、店铺选项的币种不再缺省写死 `MYR`，一律从 `country` 推导；模板另存/复制到别的店铺也按目标站点取币种。
- 价格预览、店铺/模板币种显示跟随站点；描述配图超限提示不再写死「马来站」。
- 描述配图上限仍按实测：MY=3、ID=0；PH 实测 10 张可保存（不限）；TH/SG 未实测，默认不限，可在模板/副本 `description_media_max_images` 上按店收紧。

## 2. 页面导入不再把站点写错

- 导入弹窗里手选的站点成为**权威值**，会写进采集快照的 `store.country`（马帮页面本身没有站点字段）。
- 新增导入前校验：同一家马帮店铺已记录为某站点时，本次选另一个站点会在 confirm 阶段直接拦住，避免「MY 店被重新导入成 PH」这类污染。确需迁移站点用显式 `allow_country_change: true`，并配合 `scripts/migrate_store_site.py` 重绑模板/副本。
- 店铺选项在导入时同步写入 `currency`。

## 3. 存量类目方案修复（启动自愈）

新增 `services/api/store_migrations.py`，挂进冷加载链路，随版本升级在**每台设备**自动执行、且幂等：

- `repair_local_category_profile_sources`：只对 PH 生效。历史上马来店页面采集被当成 PH 写入 `shopee-ph-*` 的方案，会被替换为同国家本土采集版本，并重绑本土模板（已有副本快照不动）。非 PH 国家绝不会套用这条规则。
- `drop_unsupported_collar_type`：清掉模板里「衣领类型 = Crew Neck」——马帮 Collar Type 枚举里没有这个值（Crew Neck 属于领口/Neckline），保留会导致下拉选不到。
- `normalize_template_currency` / `normalize_store_option_currency`：按站点纠正存量 MYR 币种。

## 4. 模板属性值一定会写进马帮

- 建自动化任务时，如果副本缺少模板里配置的属性值（模板后加的字段不会自动同步到老副本），会按「从模板补全缺失属性」同一口径**自动补齐并落盘**，只补缺、不覆盖副本已有值。此前只给一条警告，操作员不点补全就会在草稿里空着。
- 3PF 与本土走同一条补齐路径；跨境纯 CNSC 不受影响。

## 5. 运维脚本

- `scripts/migrate_store_site.py`：把一家店铺的本土模板整体迁到另一个站点（用该店自己的页面采集版本建 `shopee-<country>-*` 方案，重绑模板 + 全部副本，改 store option 的 country/currency）。支持 `--dry-run` / `--apply`。
- `scripts/repair_local_category_profile_source.py`：单次手动执行上面第 3 条的 PH 方案修复。
- `scripts/verify_site_template_rules.py`：自检所有模板/店铺选项的币种、方案 country/版本、以及残留的 `Crew Neck` 脏值。

## 升级提示

- 无新增依赖；数据结构只增字段（店铺选项 `currency`、方案修复版本），不删旧数据。
- 启动迁移只处理类目方案/模板/店铺选项这些小集合，不动任务快照；已有任务与副本快照不会被悄悄换规则。
- 每台设备升级后第一次冷加载会自动修本地 `data/store.json`，不需要手工跑脚本；想先看计划可用对应脚本的 `--dry-run`。
- 升级后建议跑一次 `python -I scripts/verify_site_template_rules.py`，应输出 `OK`。

## 验证

- 8 个店铺模板（PH×6、3PF×2，含 MY 店）各完整跑了一次刊登：8/8 保存成功；MY 草稿 18 个属性字段齐全，模板配置的 11 个值全部落库。
- 方案修复用修复前备份重放验证：PH v4/v12 正确恢复到本土采集版本，二次执行无变更；非 PH 方案不触发。
