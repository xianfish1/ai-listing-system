# v1.0.88

本版只修一处：**跨境本土 3PF 的模板默认视频选不上**（`video_upload` 落 `video_select_failed:row_not_found`）。本版同时包含 v1.0.87 的商品标题上限 120（本机部署树此前停在 1.0.86，已一并补齐）。

## 修复：3PF 默认视频选不上（`video_select_failed:row_not_found`）

- 现象：3PF 任务整条链路正常、草稿保存成功，只有视频阶段记警告：

  ```
  video_select_failed:row_not_found:{"video_id":"sg-11110106-6vd63-mtqeagzv9afb54",
    "video_title":"AL1625","library_total":"1","rows_on_page":1}
  ```

  按「视频ID」搜到的就是 **1 条**，却没认出来；退回按主 SKU 搜标题也搜不到。
- 根因：CNSC（3PF）产品页的「视频管理」表格**不把 `videoId` 渲染进行文本**，而选行逻辑用
  `row.textContent.includes(videoId)` 做匹配，永远不命中。本土页会渲染 ID，所以本土一直正常
  （2026-11-17 那次 3PF 能附上视频也是这个原因）。视频本身没问题：账号级视频库接口
  `shopee/getVideo?search_type=videoId` 能查到；带 `shop_id=2022777133` 反而返回 0 条
  —— 这个库是账号级、不按店铺过滤。
- 修法（`scripts/mabang_playwright_executor.cjs`，**只在 3PF 启用**）：
  - `uploadProductVideo` 在 `listing_mode === 'cnsc_3pf'` 时给选视频传 `{allowUniqueRow:true}`；
    `site` / `cnsc_global` 不传，走原逻辑。
  - `pickVideoLibraryRow` 新增 `acceptSingleRow`：按 ID 搜索后**只剩 1 行**就直接点该行「选择」
    （返回 `via:'only_row'`）。
  - 选完回读表单视频 URL，**必须包含该 `videoId`**，否则抛 `video_attach_mismatch`
    —— 选错/认错都不会写进草稿。
  - 失败摘要 `videoLibrarySummary` 增加 `row_samples`（行文本＋行内按钮），下次现场能直接分清
    「ID 没渲染」还是「没有选择按钮」。

- 只改了 `.cjs` 执行器，**不用重启 API**：每个任务单独起 node 进程，下一次领取任务即生效；
  正在跑的任务仍用旧代码。
