# v1.0.83

本版修**从文件夹导入商品时主 SKU 被拼进款式名**的问题。

## 修复：主 SKU 不再吞掉紧贴的款式名

- 现场：文件夹叫 `AL0839Retton`，导入后主 SKU 变成 `AL0839RETTON`；期望是 `AL0839`。
- 原因：旧的派生规则只是「取开头连续的 ASCII 字母数字，遇中文/空格/符号才停」，英文款式名没有分隔符时会整段吃进来。
- 新规则：取开头那串 ASCII 字母数字，遇到下面任一情况就截断——
  - 中文 / 空格 / 符号；
  - **「大写字母 + 紧跟小写字母」的单词起点**（`Retton`、`Ray`、`Tshirt` 这类款式名）。
- 全大写后缀保留：`YSC008P`、`AC4B7920` 这类真实 SKU 形态不受影响；年份开头（`2024夏季新款`）或纯中文名仍然回落自动编号。

| 文件夹名 | 以前 | 现在 |
|---|---|---|
| `AL0839Retton` | `AL0839RETTON` | `AL0839` |
| `AL0839RettonV2` | `AL0839RETTONV2` | `AL0839` |
| `AL0301男语言月` | `AL0301` | `AL0301` |
| `YSC008P` / `AC4B7920` | 原样 | 原样 |
| `2024夏季新款` | 自动编号 | 自动编号 |

商品名不受影响：`AL0839Retton` 仍然是商品名 `Retton`（SKU 前缀被剥掉）。

## 三处同源（避免 group_id 与 main_sku 分叉）

- `services/api/storage.py::_derive_main_sku_from_folder_name`（主 SKU）
- `workers/asset_scanner/scanner.py::_extract_group_token`（素材 group_id；调用点改为传原始大小写的目录名，不再先 `.upper()`）
- `apps/web/local-folder-batch.js::folderSkuToken`（导入去重指纹）
