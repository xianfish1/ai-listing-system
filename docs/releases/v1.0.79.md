# v1.0.79

本轮全部围绕 **CNSC 3PF（跨境本土）** 的上款流程：先让它能保存，再让它填全、跑快。所有新容错都挂在 3PF 开关上，`site` 与 `cnsc_global` 的原有路径未改动。

## 修复：3PF 保存被静默拒绝（`save_result_not_proven`）

- 现象：保存按钮点下去了，但没有成功弹窗、没有 save 响应，任务停在 `needs_confirmation`。
- 原因：3PF 页面的「交易信息」用**单一必填列「库存」**代替全球页面的泰国/广州/菲律宾三仓库存列，执行器只写价格和三仓库存，70 行 SKU 的库存全部留空，马帮因此拒绝保存且不弹任何提示。
- 现在：新增 `stock` 列定义（仅 3PF 启用，页面没有该列时跳过），值取 `sku.stock`，缺失时退回三仓之和；写入后逐行回读校验。

## 修复：`Cannot read properties of undefined (reading 'sku')`

- 原因：`validateBeforeSave` 第二次调用 `buildCNSCDomGridPlan` 时漏传 `warehousesRequired`，3PF 没有三仓列 → 返回 `ok:false`（无 `columns`）→ 下一行读 `plan.columns.sku` 抛错，整单失败且没有阶段信息。
- 现在：两处调用使用同一套 options，`plan.ok` 为假时不再读 `columns`；同时给 VXE 表格的空行加了过滤（虚拟滚动会短暂出现 undefined 行）。

## 修复：分类属性大量漏填

- 原因：马帮默认只渲染必填属性，其余折在「显示所有属性」后面；展开逻辑原来只对本土（site）生效，3PF 的 15+ 个可选属性（原产地/图案/季节/风格/领口/推荐年龄…）被当成「页面没有该属性」静默跳过。
- 现在：3PF 进入逐字段填写前先展开「显示所有属性」（选择器对 3PF 放宽，取最内层可见元素），逐字段兜底也支持；日志新增 `attributes_expanded` / `attributes_expand_failed`，可直接看到展开前后的表单项数量。

## 修复：`select_option_not_unique` 与「页面上该字段不唯一」

- 选项歧义：页面渲染的是中英双语标签（如 `棉花 (Cotton)`），按英文 `Cotton` 搜索会同时命中 `精梳棉 (Combed Cotton)`。现在按**结构化变体**收窄——候选的某个变体与搜索词完全相等才算点名命中；收窄失败才判歧义（仅 3PF）。
- 字段歧义：`尺寸` 的子串匹配会撞上物流的「包裹尺寸」（长/宽/高三个输入框）。3PF 改为按标签前缀锚定，锚不到才退回原逻辑。

## 性能：整单从约 9 分钟降到约 5 分钟量级

| 优化点 | 改前 | 改后 |
| --- | --- | --- |
| 表单项定位（`formItemByOwnLabel`） | 逐项 3 次往返，单次扫描 0.5~3 s | 一次 `evaluate` 算完，几十毫秒 |
| 每个属性扫描次数 | 3 次（找字段 / 落值 / 回读） | 1 次（复用已解析的表单项） |
| 选完选项的稳定性回读 | 每 100 ms 重扫整表 + 昂贵的选项定位器（单次迭代可达 60 s） | 直接复用表单项，仅在文本未命中时才读选项行 |
| `validate_before_save` 审计 | 546 s（对 `body *` 每个节点做样式与布局计算） | 3 s（先用 textContent 廉价预筛，最终判定仍是可见性 + innerText） |

## 稳定性

- **可选属性**填写失败不再阻断整单：记 `skipped_optional_failed` 并降级为 warning，草稿照存、任务落 `saved_with_warnings`；必填属性仍然阻断。
- 执行器超时预算与 lease 对齐（`max(300, lease×4)`），Worker 每次启动重读设置，改完 lease 重启即可生效。

## 升级后

- 重启程序即可，不需要清理任务或数据。
- 如果之前的任务是在旧版本跑失败/阻塞的，点「再次尝试」会重新走新逻辑（同一条任务记录，不会产生重复刊登）。
- 建议观察一条 3PF 任务跑通：页面「交易信息」应显示已完成，任务状态为 `saved_with_warnings`，详情里能看到跳过的可选字段。
