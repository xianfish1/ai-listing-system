# v1.0.86

本版三件事：**保存被马帮拒绝时能看见真因**、**描述配图上限可按店铺钉死**、**属性值不再「选泰国变日本」**；另外把「类目方案作用域」的存量漂移做成了可复用的修复脚本。

## 保存被拒：先说出原因，再说保存没成功

- 之前马帮前端把保存拦下来（例如「商品描述中的图片不能大于3张」），执行器读到了提示却认不出，15 秒证据窗耗尽后统一报 `save_result_not_proven`（界面「无法确认草稿已保存」），运营只能靠截图猜。
- 新增拒绝规则 `description_image_count_over_limit`：`商品描述中的图片(不能大于|不能超过|最多|不能上传|不支持|不允许)` 都能归类，`details.page_message` 带原文。
- `save_result_not_proven` 的 `details.page_messages` 现在会把**轮询期间见到的所有页面提示原文**一起带回来（以前只留命中规则的那条，其余直接丢），认不出的文案也能在任务详情里读到。

## 描述配图上限：站点策略之外，再给店铺级开关

- 站点策略不变（`services/api/description_media_policy.py`：MY 3 张、ID 0 张、其它不限）。
- 新增店铺级字段 `description_media_max_images`：`""`=跟随站点策略、`0`=描述里不插图、`N`=最多 N 张（**含尺码表那张**，即上限 3 = 尺码表 + 2 张产品图）。
  链路：店铺模板 → 副本 → `browser_inputs` → runner 覆盖站点策略；模板改动会同步到已有副本。
- 用途：马帮的「店铺国家」是页面导入时操作员选的、可能配错（现场：MY 本土店被记成 PH，按「不限」插了 10 张，保存被 Shopee 拒掉，整店 17 个任务全卡住）。把上限钉在店铺上，不用改站点国家也能止血。
- 模板卡片会显示「描述配图 · ≤N 张」，钉过上限的店一眼能看出来。

## 属性值解析：不再按子串乱认

- 根因：把模板值翻译成页面选项时用的是双向子串匹配，而选项 id 都是短数字——`"129"`（泰国）会命中 `id=1` 的「日本」，因为 `"129".includes("1")`。110/112/130/131/132/133 等 id 全部会塌到「日本」。
- 修法：解析顺序改成 **① 选项 id 完全相等 → ② 标签完全相等（去空白、忽略大小写）→ ③ 才做宽松子串匹配**，且**纯数字的值不许走 ③**；模板解析和「AI 补必填」两处都改。
- 另外兜住一种脏数据：枚举字段里出现「纯数字、但枚举里查不到」的值时，不再把它当文本打进马帮页面（以前会把 `129` 这样的内部 id 写上去），改为跳过并交给 Python 侧「方案里 id→标签」兜底。
- 新增回归用例 `scripts/verify_attribute_option_resolution.cjs`（16 条，含 `129→泰国`、`1→日本`、`999/Atlantis→不硬猜`）：`node scripts/verify_attribute_option_resolution.cjs`。

## 页面导入：站点必须手选

- 导入弹窗新增「站点」下拉，**必选**，空站点不会创建导入任务。以前这里取工作台当前店铺的国家、拿不到就填 `PH`，MY/TH 这类本土店会被整店记成 PH，站点相关规则（描述配图上限等）全部用错。
- 从店铺模板页进来时，会按**要导入的那家店**已记录的站点预填（仍是可见可改）；不认识的新店才需要手选一次。
- 店铺模板列表/卡片增加站点徽章（PH / MY / …），站点配错时不用点进模板就能发现。

## 类目方案作用域：修复脚本

- 口径（`services/api/listing_modes.py::category_profile_country`）：本土 site → 店铺国家方案；跨境 cnsc_global / cnsc_3pf → GLOBAL 方案。
- 新增 `scripts/fix_category_profile_scopes.py`：自动判断每个模板该绑哪个作用域、缺 GLOBAL 方案时用「最近一次跨境页采集快照」补建，并**联动已有副本**重算 `profile_snapshot_hash`（模板改绑本身不会同步副本，那段 sync 在 early return 之后是死代码）。
- 用法：`--dry-run` 看计划 → **先停 API**（存储层只有进程内锁）→ `--apply`（自动备份到 `data/backups/pre-category-scope-fix-*`）。

## 测试

- `node --check scripts/mabang_playwright_executor.cjs`、`node --check apps/web/app.js` 通过。
- 实机验证：本土 MY 店 17 个任务改绑后重跑 **17/17 saved**，描述配图 3 张（尺码表 + 2 张产品图）；231 份副本按作用域重绑后就绪度全绿。

## 升级提示

- 本版有后端改动（`storage` / `browser_use_runner`）：**更新后需重启 API**；前端 F5 即可。
- 新增依赖：无。
- 数据结构：新增字段 `description_media_max_images`（模板/副本），旧数据缺省为空 = 跟随站点策略，无迁移动作。
- 存量店铺若仍存在「跨境模板绑了店铺国家方案」，按需跑一次 `scripts/fix_category_profile_scopes.py`（见上）。
