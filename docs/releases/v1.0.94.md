# v1.0.94

本版只修跨境（CNSC / 3PF）自动化在「选 CNSC 店铺」和「选择折扣活动」两步上的两个报错，本土（site）路径保持原样、行为未改。

## 修复

- **`select_option_not_found`（界面：下拉里没有这个选项）——选 CNSC 店铺**
  - 现象：新开页面第一次选店铺时，下拉列表接口还没返回，5 秒读不到选项就整单失败；同一批任务重试到第 3 次（换了新页面）才选上。
  - 现在跨境选 CNSC 店铺会等 15 秒，并在选项列表为空时重开一次下拉面板（最多 2 次）；本土选店铺仍是原来的 5 秒、不重开，代码路径逐字未改。
  - 失败时的详情里会带上「期望的店名/店铺 id」和「下拉里实际有哪些选项」，能直接分清是页面没加载完还是店铺改名/换绑。
- **`cnsc_site_discount_activity_not_unique`（count=0）——选择折扣活动**
  - 这个错误码其实表示「一行都没匹配上」，不是「重复」。现在 0 条会单独报 `cnsc_site_discount_activity_not_found`，并带回期望活动 id/名称、店铺 id 和弹窗里实际的活动清单。
  - 弹窗第一次打开读到空表时会关掉重开、再等一轮（慢请求/空响应）。
  - **活动被重建换了 id 时自动接上**：如果弹窗里没有配置的 id，但存在**同名且唯一**的活动，且该行折扣率与配置的百分比一致（±1），就自动选中它、把新活动 id 写回任务快照并按新 id 回读校验，同时在执行步骤里记一条 `cnsc_site_discount_activity_replaced`；同名但折扣力度变了则拒绝替换并报 `cnsc_site_discount_activity_percent_changed`，避免悄悄换掉折扣。
  - 弹窗里确实没有对应活动（已删除/换了名字）时，仍然需要人工重新采集活动目录并重选，错误文案已直接写明。

## 可诊断性

- 自动化页补充了跨境站点价格/折扣相关错误码的中文说明（`cnsc_site_discount_*`、`cnsc_site_price_*`、`cnsc_site_picker_*`、`cnsc_target_site_*` 等），不再显示英文码。
- `app.js` 缓存版本改为 `cnsc-discount-recover-v1`，部署后刷新页面（F5）生效。

## 升级提示

- 无新增依赖；不改数据结构、不改 `data/`、`storage/` 和 `.env`。
- 执行器是每个任务新起的 node 子进程，**不需要重启 Worker**；前端改动刷新页面即可。
- 若现场是「活动已被删除」：更新后任务会给出中文提示和实际活动清单，请重新采集该店铺活动目录、在店铺模板里重选后再点「再次尝试」。
