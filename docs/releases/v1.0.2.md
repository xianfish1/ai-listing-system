## v1.0.2 · 2026-11-04

- **类型**：正式版
- **安装包**：`dist/ai-listing-system-1.0.2.zip`（校验值见 Release 中同名 `.sha256` 资产）

### 新增

- **顶栏全局更新提醒**：任何页面右上角都会显示「发现新版本 vX.Y.Z · 立即更新」，点一下直接走确认 → 下载校验 → 重启；已下载待重启时显示「vX.Y.Z 已下载 · 重启安装」。
- **标题工作台**：关键词工作台、标题规则/人群作用域、标题候选与选择落库（`apps/web/title-workbench.js`、`services/api/keyword_workbench.py`、`title_selection.py`）。
- **店铺促销重新采集**：新增采集脚本与接口，促销目录缺失时可在界面重新采集。
- **部署支持**：新增 macOS / Linux 启动脚本 `start-api.sh` 与部署指南 `docs/DEPLOY_NEW_MACOS.md`；新增 Windows 全新机器部署指南与全量部署包构建脚本 `scripts/build_deploy_package.py`。
- **运维**：新增磁盘占用清理（`services/api/disk_cleanup.py`）与素材压缩/保留策略；主库分片拆分后保存商品走快路径。

### 修复

- 页图导入、促销活动、类目子模板更新、站点尺码轴顺序、多店铺并行等多个链路的稳定性问题。
- 副本图片按素材根目录取图，避免同 SKU 重复导入后旧图顶新图。
- 本地批量导入重复目录防护（同名目录/嵌套目录直接跳过并点名）。

### 变更与不兼容

- **GitHub 仓库转为公开**：检查更新与下载安装包不再需要 Token，任何一台机器打开工作台都能看到更新提醒并直接安装；只有「发布版本」仍需要写权限 Token。

### 升级提示

- 在线更新会先把旧文件备份到 `storage/updates/backups/`，不会改动 `data/`、`storage/` 和 `.env`；失败自动回滚。
- 新增依赖：无（`requirements.txt` 未变）。
- 更新后自动重启 API；如使用自定义端口，请确认 `.env` 里的 `API_PORT`。
- 配置或数据结构是否有变化：无。

### 已知问题

- 旧版本（v1.0.1）没有顶栏提醒按钮，需要先在「设置 → 版本更新」里升级一次，之后的版本才会在顶栏提示。
