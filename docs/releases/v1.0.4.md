## v1.0.4 · 2026-11-04

- **类型**：正式版
- **安装包**：`dist/ai-listing-system-1.0.4.zip`（校验值见 Release 中同名 `.sha256` 资产）

### 修复

- **老机器在线更新被整包拒绝**：v1.0.2 / v1.0.3 的安装包里多带了一个顶层文件 `start-api.sh`，而 v1.0.1 这类老版本用自己的白名单校验，会报「安装包包含不允许的路径」直接放弃更新。v1.0.4 起安装包不再包含它——v1.0.1 / v1.0.2 / v1.0.3 都能直接更新上来。
- `start-api.sh` 改由「新机部署包」（`scripts/build_deploy_package.py`）携带，macOS / Linux 首次部署照样有它。

### 变更

- 更新包只装白名单内的路径，和所有历史版本保持兼容（本次已用 v1.0.1 的白名单逐条核对 200 个文件，0 个越界）。

### 升级提示

- **v1.0.1 及更早**：打开工作台 → 设置 → 版本更新 → 仓库填 `xianfish1/ai-listing-system`（Token 可以不填，仓库已公开）→ 保存 → 检查更新 → 立即更新。
- **v1.0.2 / v1.0.3**：直接点侧栏「有新版本 v1.0.4」，或进设置点「立即更新」。
- 在线更新会先把旧文件备份到 `storage/updates/backups/`，不改动 `data/`、`storage/` 和 `.env`；失败自动回滚。
- 新增依赖：无。配置或数据结构变化：无。

### 已知问题

- 国内网络下载 Release 资产需要代理；更新失败时在 `.env` 里配 `GITHUB_UPDATE_PROXY` 指向本机代理端口（例如 `http://127.0.0.1:7890`），重启 API 后再试。
