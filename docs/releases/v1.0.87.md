# v1.0.87

本版只修一件事：**泰国站标题不再被砍掉尾巴**（v1.0.86 的功能改动全部包含在本版里）。

## 商品标题：上限 100 → 120

- 现象：一条 106 字符的泰文标题进到马帮草稿只剩 98 字符，停在 `สำหรับเด็ก`，`1-12 ปี` 整段消失。
- 根因不在马帮：`scripts/browser_use_runner.py::_shopee_listing_title` 建任务计划时按 `SHOPEE_TITLE_MAX_LENGTH = 100` 截断，再回退到最后一个空格——`title[:100]` 是 `…สำหรับเด็ก 1`，回退空格正好剩 98 字符，和草稿里看到的一字不差。泰文信息密度低，同样的意思要更多字符，所以泰国站最容易先撞上 100。
- 修法：上限改为 **120**（Shopee 商品名本身允许 120 字符）。词边界回退逻辑不变：超过 120 仍按整词裁，不会切出半个词。
- 影响范围：上限是**全局**的，不分站点；菲律宾标题仍由标题 Skill 的「最多字符」限制在 100 生成，实际长度不变。
- 单测：`tests/test_browser_use_runner.py` 新增「106 字符泰文标题原样保留」用例，原词边界用例改为按常量断言。

## 测试

- `pytest tests/test_browser_use_runner.py`：95 项全过。

## 升级提示

- 有后端改动（`browser_use_runner`）：**更新后需重启 API**；这个文件在 worker 进程里生效，**还要重启 worker**（或等它空闲自关后按需重启）才会用新上限。
- 已经建好的任务快照里仍是旧的截断标题：要重新上架一单需点「再次尝试」才会用完整标题重建计划；副本里保存的标题本身没有丢字符。
- 新增依赖：无。数据结构：无变化。
