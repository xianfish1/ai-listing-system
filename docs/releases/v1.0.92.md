# v1.0.92

本版把标题长度提醒补到「商品维护」的基础商品编辑，并修掉基础商品维护左侧副本列表在窄侧栏里的换行错位。

## 新增

- **基础商品标题字符提醒**：标题下方实时显示「已用 N 字符 · 站点预估上限：PH 100 / 其他 120」，超过 PH 上限变橙色，超过 120 变红色。基础商品没有站点，先按最严站点提醒，最终以马帮页面为准。
- **AI 标题入口暂时隐藏**：「AI 生成标题」按钮、适用人群下拉和推荐标题区域默认不显示；节点与事件保留，恢复时去掉 HTML 里的 `hidden` 即可。

## 修复

- **基础商品维护左侧 STORE COPIES 列表**：原来店名和「已保存（有提醒）」挤在同一行，窄侧栏下状态会被拆成「（有提 / 醒）」，有的副本一行、有的两行。现在统一为两行：圆点 + 店名一行，状态单独一行且不拆字；店名过长时整行折行，悬停可看完整名称。
- 去掉列表外层 `<ul>` 的浏览器默认左侧缩进（`padding: 0`），与侧栏标题对齐。

## 继承 v1.0.91

- 店铺刊登副本标题按站点上限提醒、一键按词边界裁剪、副本列表标红。
- 执行器在标题超过马帮输入框 `maxLength` 时按控件限长裁剪并轮询回读，避免 `field_value_not_verified`。

## 验证

- 新增 `tests/test_base_product_title_ui.py`：基础标题提醒、AI 入口隐藏、侧栏两行布局与状态不换行。
- 相关 Python 测试 12 项通过。
- 浏览器实际验证：AL1622 标题 103 字符显示「超过 PH 预估上限 100」；AI 按钮与适用人群均隐藏；左侧三条副本均为「店名 / 已保存（有提醒）」两行，状态不拆字，无前端报错。

## 升级提示

- 无新增依赖；不改数据结构、不改 `data/`、`storage/` 和 `.env`。
- 基础商品标题上限是**预估**（PH 100 / 其他 120），真正上架时执行器仍以马帮页面实际 `maxLength` 为准。
- AI 标题只是隐藏，不是删除；需要恢复时去掉 `apps/web/index.html` 里 `base-maintenance-audience` 和 `base-maintenance-ai-title` 的 `hidden`。
