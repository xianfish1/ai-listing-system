# NAS 素材到产品库工作流

## 1. 目标

NAS 只作为素材仓库，Web 控制台作为产品资料和上架参数中心。

日常工作不再围绕 Excel，推荐流程：

```text
美工放素材到 NAS
-> 运营在网页扫描 NAS
-> 系统识别素材分组
-> 一键创建产品
-> 自动生成 SKU 和价格
-> 产品维护页检查/微调
-> 创建上架任务
```

## 2. 当前真实路径样例

```text
\\Juns\产品编辑部\一步履\POD款式\DL  23#成人纯棉\DL0001超天酱\超天酱-1
```

系统能从该路径识别：

```text
类目：POD 男装T恤
Group ID：DL0001
产品名：超天酱
主图：主图1.jpg
变体图：白色/黑色/灰色/粉色/紫色
尺码表：POD成人尺码表.png
源文件：1超天酱.psd
```

```text

```

但不建议现在强制整理历史素材。

## 5. 文件识别规则

```text
主图*              -> main
模特图*            -> model
白色/黑色/灰色...  -> variant
尺码表/size        -> size_chart
psd/ai/cdr/pdf     -> source
mp4/mov/avi/mkv    -> video
印花/透明图/print  -> print
```

`print` 是生产用印刷图（前印花/后印花/前胸印花图/袖口透明图…）：不进商品图、不当主图、
也不做颜色图和颜色识别（详见 `docs/POD_ASSET_RULES.md` 第 2 节）。

默认商品图顺序（2026-10-09 起）：**主图 → 模特图 → 颜色图**，最多 9 张。

颜色识别：

```text
白色 -> white
黑色 -> black
灰色 -> gray
粉色 -> pink
紫色 -> purple
红色 -> red
蓝色 -> blue
绿色 -> green
黄色 -> yellow
```

## 6. 素材完整度规则

阻断项：

```text
主图 >= 1
变体图 >= 1
SKU >= 1
价格 >= 1
SKU 图片匹配
标题已填写
重量已填写
```

提醒项：

```text
视频缺失
模特图缺失
尺码表缺失
```

当前视频缺失不阻断。

## 7. Web 操作步骤

### 扫描素材

```text
1. 打开 http://127.0.0.1:8787
2. 进入“素材库”
3. 填入类目：POD 男装T恤
4. 填入 NAS 路径
5. 点击“扫描素材”
```

支持两种扫描方式：

```text
单款式目录：
\\Juns\...\DL0001超天酱\超天酱-1

上级目录批量扫描：
\\Juns\产品编辑部\一步履\POD款式\DL  23#成人纯棉
```

上级目录扫描会先寻找包含 Group ID 的款式目录，例如：

```text
DL0001 超天酱牛角袖
DL00010玩具总动员
DL00011...
```

为了避免 NAS 大目录扫描过慢，网页提供“最多扫描文件数”。

扫描模式建议：

```text
自动识别：单款式目录优先，例如 DL0001超天酱\超天酱-1
上级目录批量：扫描类目上级目录，例如 DL  23#成人纯棉
当前目录递归：只按当前目录递归，不主动拆分上级款式组
```

### 创建产品

```text
1. 在“素材分组”找到 DL0001
2. 点击“创建产品”
3. 系统自动进入“产品维护”
```

素材分组支持：

```text
勾选批量创建
主图缩略图预览
素材质量状态
查看素材详情
打开款式目录
打开主图文件
创建产品
```

素材质量状态会在批量扫描后直接显示：

```text
可建产品：主图、变体图等关键素材已满足
需补素材：缺主图、缺变体图、图片异常等阻断项
提醒项：缺模特图、缺尺码表、缺视频、缺源文件
已入库：该款式已有产品，不再重复创建
```

素材详情会按以下类型分区展示，并支持像 NAS 一样打开文件或打开所在目录：

```text
主图
模特图
变体图
尺码表
视频
源文件
```

系统会自动生成：

```text
产品资料
主图
素材根目录
颜色 x 尺码 SKU
测试价格
上架前检查
```

### 产品维护

需要人工确认：

```text
标题
重量
长宽高
主图
SKU
价格
描述
上架前检查
```

### 创建上架任务

```text
1. 上架前检查显示“可上架”
2. 点击“创建上架任务”
3. 任务进入任务中心
4. 导出预览会先拦截缺失字段，再输出马帮 Excel 生成前检查结果
```

## 8. 异常处理

### 找不到 Group ID

检查上级目录是否包含类似：

```text
DL0001超天酱
```

### 没有变体图

检查文件名是否包含颜色：

```text
白色
黑色
灰色
粉色
紫色
```

### 上架前检查不通过

在产品维护页查看红色阻断项，修复后重新保存。

### 视频缺失

目前不阻断，只提醒。后续如果平台强制视频，再改为阻断项。

## 9. 角色分工

美工：

```text
按款式把主图、模特图、颜色图、尺码表、源文件放入 NAS。
```

运营：

```text
扫描素材，创建产品，检查标题、重量、SKU、价格。
```

自动化执行器：

```text
只读取产品库数据，不直接猜文件。
```

## 10. 现阶段结论

当前推荐保持：

```text
NAS = 素材仓库
Web 控制台 = 产品和上架参数中心
任务中心 = 自动化执行入口
Excel = 后续可选导入/导出工具
```
