# 店铺模板同店复制设计

## 目标

在「店铺模板」列表的模板卡片上增加「复制」入口：一键把当前模板复制成同一店铺下的新模板，命名自动加 `- 副本`，随后直接打开编辑器继续改差异项再保存。

## 与「另存为模板」的区别

| | 卡片「复制」 | 编辑器「另存为模板」 |
| --- | --- | --- |
| 目标店铺 | 固定为源模板的店铺 | 由操作员另选店铺 |
| 店铺绑定值（类目、必填属性、价格、尺码价、促销活动、水印） | 全部照抄 | 换店铺时清空，同站点才保留类目与价格 |
| 用途 | 同店做第二个变体（改类目、活动、价格、描述） | 把整套配置搬到另一个店铺 |

两条路径互不影响：`/copy` 继续服务「另存为模板」，新增 `/duplicate` 只服务同店复制。

## 行为

1. 模板卡片操作区为「维护 / 复制 / 删除」，`复制` 排在中右位置。
2. 点击后调用 `POST /api/store-templates/{id}/duplicate`，服务端把源模板整份深拷贝。
3. 新模板重新生成 `id` 与 `current_version_id`，`version` 回到 1，`created_at` / `updated_at` 取当前时间；同时写入一条 `store_template_versions` 版本快照，与新建模板一致。
4. 模板名默认是 `<原模板名> - 副本`；同店已有同名（未归档）模板时依次追加 ` (2)`、` (3)`……，不覆盖既有模板。
5. CNSC 模板复制后按副本自身配置重新计算 `missing_configuration` 与 `status`：缺配置的副本仍是 `needs_configuration`，不会因为复制而被放行。
6. 复制成功后前端刷新模板列表并直接打开新模板的编辑器，提示「已复制模板，可继续修改后保存」。
7. 复制的模板与源模板完全独立：刊登副本、自动化任务和后续编辑都只认各自引用的模板。

## 复制的字段范围

除身份与时间字段外全部保留，包括：店铺与站点、刊登模式、类目方案与必填属性值、原价 / 售价 / 尺码价、促销活动与折扣标签、描述方案与固定描述、尺码与 SKU 模板、默认 SKU、交易信息（库存 / 重量 / 包裹尺寸）、尺码图（上传图或马帮模板）、主图与产品图水印、CNSC 全球价档位、目标站点店铺、仓库库存默认值、导入 SKU 行。

## 非目标

- 不复制店铺刊登副本和自动化任务（它们仍属于源模板名下）。
- 不做跨店铺复制，也不改动「另存为模板」的现有清空规则。
- 不复制归档模板：已归档模板不在卡片列表中，源模板被归档时接口返回 404。
- 不新增确认弹窗之外的批量复制与多选复制入口。

## 验收标准

- 卡片上出现「复制」按钮，点击后同店多出一份 `- 副本` 模板并自动打开编辑器。
- 副本的促销活动、水印、类目属性、价格、描述方案与源模板一致（区别于「另存为模板」）。
- 连续复制同一模板得到 `X - 副本`、`X - 副本 (2)`，互不覆盖。
- 复制不修改源模板，且不产生新的刊登副本或任务。
- 新增 pytest 覆盖存储层、接口层和前端接线断言，既有 109+ 用例保持通过。
