# 马帮尺码图与水印采集设计

## 目标

从马帮 Shopee 商品编辑页只读采集尺码图和水印配置，导入为可维护的店铺模板数据；绝不触发马帮保存、发布、刊登或提交。

## 尺码图：两个独立来源

马帮页面的尺码图有两种互不替代的数据，必须同时采集。

1. **上传图片**：读取当前商品已上传的尺码图 URL，下载到本系统资产库，并填入店铺模板的“上传图片”来源。编辑模板时显示该图片缩略图；再次保存模板时必须保留资产 ID、预览 URL 和文件名。
2. **选择模板**：读取马帮尺码图下拉菜单中的全部模板，保存为该店铺的尺码图模板目录，包含稳定 ID、名称和可用的缩略图/预览地址。

店铺模板页面的来源切换规则：

- 选择“上传图片”时，仅显示上传控件和当前图片缩略图。
- 选择“选择模板”时，仅显示本店铺已采集的模板下拉框与所选模板缩略图。
- 不显示“马帮采集”作为第三种来源；马帮只是上述两类数据的只读来源。
- 已有旧数据若标记为 `mabang_capture`，打开时迁移为“上传图片”；无法取得图片资产时显示明确的待重新上传提示，不静默清空。

## 水印

采集器在读取前可临时展开马帮“添加水印”菜单，并在采集结束后恢复原状。读取菜单实际渲染的选项及其 Vue 状态，保存为对应店铺的水印目录：

- `template_id`
- 中文名称
- 缩略图地址（存在时）

采集结果仅建立“可选择的水印目录”，不对马帮商品应用水印。店铺模板分别选择“主图水印”和“产品图水印”；两者均从同一店铺目录中选择，并显示缩略图。

若菜单成功展开但未识别任何选项，导入预览应显示“水印目录未读取到”，不得伪报已保存。

## 保存边界

采集分两个阶段：

1. “采集当前页”只保存一份待确认快照，不写业务模板。
2. “确认导入”原子性写入店铺、类目规则、促销活动、尺码图资产、尺码图模板目录、水印目录和店铺模板。

重新编辑并保存模板时，未在表单中主动替换的导入字段必须保留，特别是 `size_chart_asset_id`、`size_chart_preview_url`、水印选择和交易信息。任何导入失败须返回可见错误，不写入半成品模板。

## 验收标准

- 马帮上传的尺码图导入后，在“上传图片”模式显示缩略图，刷新页面及再次保存后仍存在。
- 马帮“选择模板”列表导入后，切换到“选择模板”模式可在下拉框选择这些模板。
- 水印菜单读取到选项时，模板页的主图和产品图水印下拉均出现选项和缩略图。
- 水印菜单未读取到选项时，预览明确提示未读取，不产生空目录覆盖。
- 全链路没有调用马帮保存、保存并刊登、刊登、发布或提交按钮。
