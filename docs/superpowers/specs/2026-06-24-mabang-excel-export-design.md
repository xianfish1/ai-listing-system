# 马帮 Excel 导出改造设计

## Summary
把当前项目的主输出收束为基于 `产品导入示例模板 (1).xlsx` 的马帮批量导出。
导出只做文件，不接马帮 API；图片字段先直接写 NAS 路径，保证 Excel 里拿到的是可追溯的本地文件位置。

## Key Changes
- 新增一个模板驱动的 Excel 导出模块，直接复制并填充参考模板，保留 `产品导入列表 / 产品导入示例 / 字段说明` 三个 sheet 和原有样式。
- 导出规则按 `1 个产品 = 1 条主行 + N 条子 SKU 行` 展开。
- 主行只填当前系统能稳定映射的字段：主 SKU 编号、中文名、目录、品牌、成本价、起订量、重量、尺寸、主图/多属性图/描述图、原厂 SKU 等。
- 子 SKU 行从现有 `product / sku / asset / price` 数据生成，图片列写 NAS 路径；缺少英文名、日文名、申报信息等字段时保持空白。
- 增加一层本地目录映射配置，不直接复用 Shopee 类目。
- UI 增加“导出马帮模板”批量按钮，默认导出当前勾选产品，并可保存一份审计副本到 `storage/exports`。
- 旧的浏览器刊登按钮和文案不再作为活跃入口，避免继续把系统引向页面执行。

## Validation
- 模板回归：确认 sheet 名、合并结构、列数和样式保留。
- 数据回归：多 SKU 产品能展开为主行 + 子 SKU 行，Excel/openpyxl 可正常打开。
- 失败回归：缺少主 SKU、主图、目录映射时，导出前直接拦截并返回可读错误。
- 冒烟回归：从勾选产品到下载 `.xlsx` 的全链路可跑通。

## Assumptions
- 第一阶段只做“选中批量导出”，不接马帮 API。
- NAS 路径直接写入 Excel；导入机器需要能访问同一 NAS 共享。
- 不支持的字段保持空白，不自动编造英文名、日文名或申报信息。
- 导出时默认同时留存一份副本到 `storage/exports`，方便审计和复查。
