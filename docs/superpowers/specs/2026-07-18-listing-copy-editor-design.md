# 店铺刊登副本维护编辑器设计

## 目标

将“检查副本”从标题、描述的简单确认框升级为刊登前的完整维护入口。用户可以在生成自动化任务前检查并修改图片、尺码图、SKU 价格、库存和交易信息；只有副本通过完整性检查后才能生成任务。

## 编辑范围

编辑器分为六个区域：

1. 基本信息：商品标题、描述生成方案、促销活动、商品描述。
2. 商品图片：缩略图、拖拽排序；第一张图片作为主图。
3. 尺码图：显示当前尺码图，支持上传替换。
4. SKU 明细：显示 SKU、颜色、尺码，并可编辑库存、原价和折后价。
5. 交易信息：统一库存、重量、包裹长宽高。
6. 完整性检查：使用中文提示缺失或过期配置，并可定位到对应编辑区域。

## 数据规则

- 副本是自动化任务的最终输入快照。用户在副本中的手工修改优先于之后的模板修改。
- 商品图片按 `product_images` 的顺序保存；第一张同步为 `main_image`。
- SKU 的库存保存在 `listing_skus`；原价和折后价保存在对应 `listing_prices`。
- 交易信息保存到副本，并在构造 Browser-Use 输入时进入 `transaction_info`。
- 尺码图保存上传资源标识、预览 URL、文件名和本地路径（有值时）。
- 保存操作必须在同一次存储锁内更新副本、SKU、价格和图片顺序；任何校验失败都不写入部分数据。
- 保存后重新计算 readiness，并返回刷新后的副本详情。

## 价格规则

- 默认折扣为六折，即折后价为原价的 60%。
- 用户可以直接修改每个 SKU 的原价或折后价。
- 编辑原价且没有显式改动折后价时，前端自动计算六折价格。
- 每个 SKU 可以有不同价格，例如 S 原价 90，其他尺码原价 180。

## 完整性提示

后端保留稳定的字段代码，前端显示中文：

- `size_chart_image`：缺少尺码图
- `description_profile_version_id`：请选择描述生成方案
- `promotion_activity_expired`：促销活动已过期，请重新选择
- `listing_skus`：缺少 SKU 明细
- `listing_prices`：缺少 SKU 价格
- 交易信息字段：提示对应的库存、重量或包裹尺寸缺失

当存在任何错误，或描述仍处于待生成状态时，禁用“生成自动化任务”。

## 非目标

- 不在本功能中发布商品。
- 不修改或保存马帮页面。
- 不伪造马帮店铺、类目或促销活动 ID。
- 不自动覆盖用户已经维护过的副本字段。
