# 店铺配置、素材自动化与桌面工作台设计

日期：2026-07-19  
状态：已完成分节确认，等待书面规格复核

## 1. 目标

本设计完善从店铺模板维护到马帮草稿保存的真实工作流，并重构桌面端界面：

1. 区分促销活动“确实过期”和“暂时无法解析”。
2. 支持店铺模板另存到其他店铺，并重新获取目标店铺配置。
3. 采集成功后直接回到刚导入模板继续补全。
4. 支持商品视频、尺码图来源与快照。
5. 采集并使用马帮原生水印模板，区分主图和后续产品图。
6. 提供只展示真实运行数据的首页、顶部导航和设置页面。
7. Worker 始终只保存马帮草稿，保存后关闭页面并继续领取下一任务。

## 2. 非目标

- 不支持手机端或响应式手机布局；最小目标是桌面工作台，窄窗口允许横向滚动。
- 不接入或模拟销售额、店铺余额、Token 余额和平台经营指标。
- 不在本系统合成水印，不保存水印 PNG，不实现文字水印和平铺水印。
- 不为视频转码；只支持 MP4。
- 不自动选择替代促销或替代水印。
- 不允许自动化刊登、发布、保存并刊登或提交审核。

## 3. 现有基础与改造边界

现有系统已经具备：

- 基础商品、店铺模板、店铺刊登副本和自动化任务。
- 店铺级促销目录与马帮当前页只读采集。
- 类目必填项、交易信息、SKU、尺码图和促销数据采集。
- AI 模型连接和 Anthropic Messages 兼容调用。
- 刊登副本编辑、图片排序、尺码价格和任务分阶段执行。
- Worker 领取、租约、保存证据和保存后关闭页面。

本次不重写这些模块，只增加明确的数据类型、状态和操作界面。采集脚本负责读取真实马帮状态；服务端负责规范化、归属校验和持久化；Worker 只消费已保存的任务快照。

## 4. 促销活动语义

### 4.1 状态

促销选择使用以下业务状态：

| 状态 | 判定 | 处理 |
| --- | --- | --- |
| `available` | 当前店铺目录存在，且未明确过期或停用 | 可直接选择和执行 |
| `expired` | `end_at` 已过去，或马帮明确返回过期状态 | 显示“促销活动已过期” |
| `unresolved` | 本地目录缺失、脚本找不到、页面未加载完成或身份匹配失败 | 显示“促销活动未解析” |
| `unconfigured` | 模板或副本从未选择活动 | 显示“活动未配置” |

“不在本地目录”及“马帮选择器中暂时找不到”都不能推断为过期。

### 4.2 任务创建和执行

`expired`、`unresolved` 和 `unconfigured` 是任务创建时可见的非阻断警告，用户仍可生成任务。Worker 执行时必须：

1. 按活动 ID 在目标店铺重新匹配。
2. ID 不可用时，只能使用经过校验的可读身份组合匹配：活动名称、折扣和有效期。
3. 匹配到唯一活动后继续。
4. 仍无法匹配时进入 `needs_confirmation`，不得跳过促销后保存。

系统永不自动替换为同折扣或名称相近的其他活动。

## 5. 店铺模板另存

### 5.1 操作

店铺模板编辑器增加 `另存为模板`。操作员选择目标店铺和新模板名称，系统创建新记录，源模板不变。

### 5.2 同平台、同站点

保留：

- 平台类目和类目必填属性值。
- 原价、六折售价和按尺码原价覆盖。
- 尺码、SKU 模板、交易信息默认值。
- 描述生成方案。
- 尺码图资产。

清空：

- 促销活动。
- 主图水印。
- 产品图水印。

### 5.3 跨站点

只保留站点无关值：

- 尺码和 SKU 结构。
- 库存、重量和包裹尺寸。
- 描述生成方案。
- 尺码图资产。

同时清空类目、币种、价格、类目必填属性、促销和两类水印。模板进入需要采集或补全状态。

### 5.4 获取目标店铺配置

选择目标店铺后由操作员显式点击 `获取目标店铺配置`。系统打开或复用已登录马帮页面，执行只读采集，并校验采集页面店铺 ID 与目标店铺一致。

系统不在后台静默切换店铺。店铺身份不一致时拒绝导入，不覆盖已有目录。

目标店铺配置包括：

- 平台类目和当前页必填项。
- 当前店铺完整促销活动目录。
- 当前店铺完整水印模板目录。
- 当前页面已选尺码图和交易信息。

## 6. 马帮采集完成后的导航

确认导入成功后：

1. 关闭马帮导入弹窗。
2. 切换到顶部导航的 `店铺模板` 页面。
3. 打开刚创建或更新的模板编辑器。
4. 如果有缺失必填项，滚动并聚焦第一个缺失字段。
5. 如果没有缺失项，显示采集摘要和更新时间。

采集失败时保持弹窗和原数据，不进行跳转。

## 7. 视频

### 7.1 所有权

基础商品持有最多一个商品视频。视频可由 NAS 扫描识别或在基础商品维护中上传。店铺刊登副本创建时记录视频资产快照；副本可单独替换或删除，不修改基础商品和其他副本。

店铺模板不持有商品专属视频，只保存是否尝试上传商品视频的规则。

### 7.2 规格

- 格式：仅 MP4。
- 时长：10–60 秒，含边界。
- 分辨率：宽和高均不得超过 1280 像素。
- 文件大小：不得超过 30 MB。
- 不做转码或自动裁剪。

服务端保存视频元数据和校验结果：文件大小、宽、高、时长、校验时间及错误代码。前端显示文件名、大小、时长、分辨率、预览和替换/删除操作。

### 7.3 失败行为

- 没有视频：黄色提醒，不阻止副本保存或任务创建。
- 格式、时长、分辨率或大小不合规：显示具体错误；Worker 跳过视频上传并继续保存草稿。
- 上传时马帮控件失败：记录 `video_upload` 阶段警告并继续。

视频被跳过后，任务最终可进入 `saved_with_warnings`，不能显示为无警告成功。

## 8. 尺码图

店铺模板的尺码图来源必须明确为：

- `upload`：操作员上传图片。
- `template`：从已有尺码图模板中选择。
- `mabang_capture`：从马帮页面采集后下载为本地资产。

模板保存来源、资产 ID、预览地址和采集元数据。创建刊登副本时为该副本创建不可变资产快照。模板以后换图只影响新副本；旧副本只有在编辑器中显式替换时才变化。

自动化任务只使用刊登副本的尺码图快照，不在执行时回退到 NAS 或模板最新图片。

## 9. 马帮原生水印

### 9.1 店铺水印目录

马帮只读采集打开 `添加水印` 后，读取当前店铺全部可用模板：

- 马帮水印模板 ID。
- 可读名称。
- 缩略图或预览元数据（马帮可提供时）。
- 店铺 ID。
- 采集时间和来源页面。

模板选择必须按 ID，必要时使用唯一的名称校验；禁止按列表位置点击。目录按店铺隔离，失败采集不得覆盖最近一次有效目录。

### 9.2 两类选择

每个店铺模板和刊登副本分别保存：

- `main_image_watermark`：只作用于图片序列第 1 张。
- `product_image_watermark`：作用于图片序列第 2 张至最后一张。

两类水印都可独立关闭，并可选择不同马帮模板。另存到其他店铺时两项均清空。

### 9.3 Worker 执行

商品图上传和顺序确认后，Worker 独立执行两个阶段：

1. `apply_main_image_watermark`
2. `apply_product_image_watermark`

每个阶段先确认水印模板存在且身份唯一，再选择对应图片范围并调用马帮原生水印功能。不能将主图水印错误应用到第 2 张以后，也不能将产品图水印应用到主图。

任一阶段失败只跳过该类水印，另一类继续尝试，随后继续保存草稿。阶段结果记录：水印角色、模板 ID 和名称、失败原因、受影响图片序号及截图证据。任务最终为 `saved_with_warnings`。

## 10. 自动化阶段和结果

标准阶段按顺序记录：

1. 店铺与类目。
2. 促销活动。
3. 产品图上传和排序。
4. 主图水印。
5. 产品图水印。
6. 视频上传。
7. 尺码图。
8. SKU、价格和库存。
9. 交易信息。
10. 保存草稿。
11. 关闭页面并继续下一任务。

阶段结果统一包含 `status`、`started_at`、`finished_at`、`code`、`message`、去敏详情和证据引用。`status` 为：

- `succeeded`
- `skipped`
- `warning`
- `failed`
- `needs_confirmation`

允许继续的警告仅包括视频缺失/无效/上传失败，以及任一类水印失败。促销无法确认、必填项缺失、页面身份不一致和保存结果不明确必须阻断。

任务终态增加 `saved_with_warnings`。它表示马帮草稿已取得有效保存证据，但存在已记录的可跳过素材警告。只有取得保存证据后才能使用 `saved` 或 `saved_with_warnings`。

保存成功后关闭当前马帮任务页面，Worker 再领取下一任务。页面关闭失败记录警告，但不能重复保存同一草稿。

## 11. 桌面工作台

### 11.1 导航

彻底移除左侧深色导航，改为固定顶部导航：

`首页`、`商品维护`、`店铺模板`、`刊登副本`、`自动化任务`、`文件管理`、`设置`

顶部右侧显示马帮连接、Worker 状态和刷新操作。页面按桌面端设计，不提供手机布局；低于最小宽度时保持控件尺寸并允许横向滚动。

### 11.2 视觉

- 浅蓝灰页面背景和白色平面面板。
- 蓝色用于主操作和正常进度。
- 橙色用于等待、提醒和已跳过。
- 红色只用于阻断错误。
- 面板圆角 6–8px，避免过度半透明和装饰。
- 首页可使用宽松布局，维护页、任务页和设置页保持较高信息密度。

### 11.3 首页数据

首页是刊登自动化运行总览，只展示数据库和运行状态中可验证的数据：

- 基础商品、店铺模板、待检查副本数量。
- 待执行、执行中、已保存、警告保存和失败任务数量。
- 当前批次进度。
- Worker 心跳和马帮连接状态。
- 最近运行日志。
- 最近保存成功、警告保存和失败商品。
- 促销、水印或类目目录需要重新采集的店铺数量。

首页不显示销售额、余额、Token 余额和虚构经营图表。

### 11.4 动态“继续工作”

首页唯一主操作按照以下优先级导航：

1. 最早的阻断失败或人工确认任务。
2. 最早的待检查刊登副本。
3. 有待执行任务但 Worker 不可用时，进入自动化任务页。
4. 已有基础商品但没有副本时，进入复制到店铺模板流程。
5. 没有基础商品时，进入从 NAS 创建。

按钮文本必须说明目的，例如 `继续工作：检查 3 个刊登副本`。它只导航，不直接创建任务或保存马帮草稿。

## 12. 设置页面

设置页采用左侧分组、右侧详情：

### 12.1 AI 模型

管理已有模型连接：名称、Anthropic API 兼容地址、密钥更新、模型 ID、默认连接和连通性测试。密钥只能写入或轮换，不回显明文。保存后后续描述请求立即使用新设置。

### 12.2 马帮连接

显示登录状态、采集浏览器连接、最后检查时间、连接错误和重新连接操作。不得在前端展示会话 token 或带敏感参数的完整 URL。

### 12.3 自动化 Worker

显示进程状态、Worker ID、最后心跳、当前任务和错误。连接参数更改后显示“需要重启”，不强行中断正在运行的任务。

### 12.4 NAS 与素材

配置默认 NAS 根目录、访问检测和默认扫描模式。保存后下一次扫描立即使用新值，不中断当前扫描。

### 12.5 店铺采集

按店铺展示类目规则、促销目录和水印目录的最后采集时间、数量、状态及重新采集入口。重新采集仍要求操作员显式打开目标店铺页面并校验店铺身份。

### 12.6 系统安全

显示不可编辑策略：`只保存草稿`、`禁止发布`。设置页不能提供开启发布的开关，API 也不接受发布权限变更。

## 14. API 能力

沿用现有 API 风格，提供以下能力：

- 店铺模板另存和目标店铺归属校验。
- 查询店铺促销目录和水印目录。
- 采集运行预览中返回完整促销、水印、尺码图和视频相关结果。
- 确认导入时原子更新有效目录和模板；失败不覆盖。
- 上传、验证、替换和删除基础商品或副本 MP4 视频。
- 查询尺码图模板，上传尺码图，并为副本创建快照。
- 提供首页聚合数据和动态下一步动作。
- 查询及更新运行配置、测试 AI/NAS/马帮连接。
- 自动化任务按阶段回写警告、错误和保存证据。

读取接口不得返回加密密钥、马帮会话凭据或未去敏堆栈。

## 15. 错误与恢复

| 场景 | 结果 | 是否继续保存 |
| --- | --- | --- |
| 视频缺失或规格无效 | 记录黄色警告并跳过视频 | 是 |
| 视频控件上传失败 | 记录 `video_upload` 警告 | 是 |
| 主图水印失败 | 主图保留未加水印，记录角色和范围 | 是 |
| 产品图水印失败 | 第 2 张以后保留未加水印，记录角色和范围 | 是 |
| 促销未解析 | 进入人工确认 | 否 |
| 店铺身份不一致 | 采集或执行失败，不覆盖目录 | 否 |
| 必填项缺失 | 标记具体字段 | 否 |
| 保存结果不明确 | `needs_confirmation`，禁止再次自动点击保存 | 否 |
| 保存成功但关闭页面失败 | 保存终态带关闭警告，不重复保存 | 已保存 |

## 16. 迁移和兼容

- 旧模板没有水印字段时按两类水印均关闭处理。
- 旧基础商品没有视频元数据时按 `missing` 处理；首次维护或任务创建时补充校验。
- 旧尺码图字段迁移为 `upload` 或已有本地资产来源，并为新副本创建快照。
- 旧促销警告需要重新计算；不得把缺失目录继续映射为 `expired`。
- 旧已保存任务保持历史状态，不回写 `saved_with_warnings`。
- 迁移保留未知旧字段，不删除用户数据。

## 17. 测试

### 17.1 单元测试

- 促销四种状态判定和“缺失不等于过期”。
- 同站点和跨站点另存字段保留/清空矩阵。
- MP4 格式、10/60 秒边界、1280 像素边界和 30 MB 边界。
- 尺码图快照不随模板更新变化。
- 主图为位置 1，产品图为位置 2 以后。
- 水印目录按店铺隔离和 ID 唯一匹配。
- 动态“继续工作”优先级。
- 设置热更新和 `restart_required`。

### 17.2 API 与存储测试

- 另存模板不修改源模板。
- 店铺身份不一致时不写入促销或水印目录。
- 采集成功原子更新目录和模板。
- 视频上传校验及错误响应不泄露本地敏感路径。
- 首页聚合值与底层商品、模板、副本和任务一致。
- 安全设置不可修改，发布权限请求被拒绝。

### 17.3 浏览器与 Worker 测试

- 采集全部水印模板，而非只读当前选择。
- 按 ID 和名称校验选择主图/产品图水印，不按位置选择。
- 两类水印分别选择正确图片范围。
- 单类水印失败或视频失败后仍保存，并产生 `saved_with_warnings`。
- 促销无法解析时进入人工确认，不保存无活动草稿。
- 保存成功后关闭页面并领取下一任务。
- 自动化路径中不存在刊登或发布点击。

### 17.4 UI 验证

使用桌面浏览器至少验证 1440×900 和 1920×1080：

- 顶部导航、首页主区和右侧状态栏无重叠。
- 设置页分组、表单和敏感字段显示正确。
- 店铺模板另存、活动/水印选择和采集后聚焦正常。
- 视频、尺码图和水印状态在刊登副本中可检查。
- 中文错误信息不显示内部字段名和原始堆栈。

## 18. 验收标准

- 只有真实过期的活动显示“促销活动已过期”。
- 模板可另存到目标店铺，且店铺绑定配置不会跨店复用。
- 采集完成自动打开新模板并定位第一个缺失项。
- 只有合规 MP4 会尝试上传；无效视频被明确记录并跳过。
- 尺码图拥有明确来源，并在副本中成为独立快照。
- 可采集当前店铺全部马帮水印模板。
- 主图和第 2 张以后的产品图可以使用不同水印。
- 单类水印失败不会阻止草稿保存，任务记录完整错误点。
- 首页只展示真实运行数据，并通过“继续工作”导航到正确步骤。
- 设置页统一管理现有配置，连接类改动提示重启。
- 自动化始终只保存草稿；成功后关闭页面并继续下一任务。

## 19. 推荐实施顺序

1. 促销状态、模板另存和目标店铺目录数据模型。
2. 水印目录采集、模板选择和 Worker 两类水印阶段。
3. 视频资产校验、编辑器和 Worker 跳过策略。
4. 尺码图来源和副本快照统一。
5. 自动化阶段结果、`saved_with_warnings` 和首页聚合接口。
6. 顶部导航、首页和设置页桌面端重构。
7. 真实马帮只保存草稿试运行与回归验证。
